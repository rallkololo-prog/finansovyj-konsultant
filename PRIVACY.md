# Политика конфиденциальности

**Приложение «Финансовый консультант» не собирает, не хранит и не передаёт персональные данные.**

## Что происходит с файлом выписки

Файл PDF, который вы выбираете, читается **локально в браузере** вашего устройства. Он не отправляется
на сервер: у приложения нет бэкенда, нет базы данных и нет внешней аналитики. После закрытия вкладки
файл нигде не остаётся, кроме вашего собственного файла на диске.

## Что хранится на устройстве

Разобранные операции, ваши уточнения категорий, доходы, цели накоплений и настройки периода хранятся
в `localStorage` браузера — то есть только на вашем устройстве. Их можно удалить кнопкой
«Очистить данные» или очисткой данных сайта в браузере.

## Передача данных третьим лицам

Не осуществляется. Приложение не использует сторонние счётчики, рекламные сети и облачные сервисы.
Единственный внешний запрос — необязательная загрузка VK Bridge при открытии внутри ВКонтакте
(`unpkg.com`), без передачи каких-либо ваших данных.

## Ссылки

Открывая приложение по адресу GitHub Pages, вы взаимодействуете с серверами GitHub так же, как при
посещении любого сайта: они видят IP-адрес и заголовки браузера. Это стандартное поведение хостинга
и не связано с содержимым ваших выписок.
