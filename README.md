# Финансовый консультант

Веб-приложение, которое читает PDF-выписки **Т-Банка** и **Сбера** и показывает, куда уходят деньги:
категории, привычки, подписки, аномалии, калькулятор экономии и «а что, если бы я экономил».

Всё считается **в браузере**. Файл выписки никуда не отправляется — у приложения нет сервера,
нет базы данных и нет аналитики. Операции разбираются на устройстве и лежат в `localStorage`.

**Открыть:** https://rallkololo-prog.github.io/finansovyj-konsultant/

## Что внутри

- `index.html` — собранное приложение (один файл, все стили и скрипты встроены). Работает и с диска.
- `manifest.webmanifest`, `sw.js`, иконки — установка на телефон и офлайн-режим (PWA).
- `app/` — исходники: `app.js` (интерфейс и страницы), `engine.js` (пересчёт любых периодов),
  `pdfread.js` (разбор PDF), `classify.js` (правила категорий), `import.js` (сборка данных),
  `pwa.js` (service worker, установка, обновления), `app.css`.
- `tools/build.js` — сборка: встраивает стили и скрипты в `index.html` и собирает папку для хостинга.
  Запуск: `node tools/build.js`.
- `pipeline/` — Python-конвейер для пакетного разбора выписок (не нужен для работы приложения):
  `pdf_extract.py` → `pdf_runs.py` → `parse_tx.py` / `parse_sber.py` → `classify*.py` → `build_data.py`.

## Возможности

- Произвольный период: пресеты или две даты, все цифры пересчитываются на выбранные дни.
- Два банка одновременно: переключатель «Оба банка / Т-Банк / Сбер», переводы между своими картами
  не считаются расходом.
- Рекомендации с суммами, достоверностью и приоритетом; заметка «ставки прекращены» исключает их из экономии.
- Стриминги и подписки отдельно от связи; страница «Непонятные траты» со справками по ИП и выбором категории.
- Калькуляторы: «Мои данные» (доходы и обязательные расходы), «Разделить счёт», «Накопления».
- Мобильная версия: нижняя навигация, таблицы превращаются в карточки.

## Ограничения

Категория — это название магазина, а не состав чека. Подписки — кандидаты на проверку,
а не утверждение «вы этим не пользуетесь». Сканы и фото выписок не читаются: нужен PDF с текстовым слоем.
Суммы «за 5 лет» — арифметика, а не обещание.

## Приватность

В репозитории нет и не должно быть персональных данных: ни выписок, ни операций, ни номеров карт.
Данные появляются только в браузере того, кто загрузил свой PDF. Кнопка «Вернуть демо-данные»
очищает загруженное.

## Лицензия

Код можно читать и учиться на нём. Для повторного использования в своих продуктах свяжитесь с автором.
